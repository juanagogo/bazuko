This is a highrise building model made in blender 3d with the 2.81 version. It doesn't contain any texture so you don't have to worry about that. It does contain a glass and a glossy shader used respectivly for the windows and balcony glass, if they do not load, you can fix them in blender, just create a new glossy material and set the roughness to 0.064 and create a  glass material and set the roughness at 0.074.

If the model doesn't work, you can contact me and i will do my best to fix it. If you are happy with the model, don't forget to like and review, Thank you!

Disclamer: This model does not contain any interior or roof design.
